# nonogram
PNG・JPEG・WebPからノノグラムを作成します。画像の変換はブラウザ内で行います。

従来のカラー問題に対応するPNGは、画像を選ぶとそのまま遊べます。完全に透明なマスは空白として扱います。盤面から同じ画像の白黒プレビューも開けます。JPEG・WebPではプレビューでカラーと白黒を切り替えられます。カラーでは近い色を最大7色にまとめ、透明な部分や白に近い部分を空白にします。

白黒の境目は画像内の明暗の分布をもとに自動で選びます。プレビューで境目とマス数を調整してから遊べます。最長辺が200ピクセルまでの画像は初期状態で元のマス数を使います。さらに大きい画像には最長辺40マスを提案し、縦横比を保ったまま200マスまで変更できます。

盤面の「なぞり塗り」をオンにすると、指やマウスで通ったマスをまとめて塗れます。盤面をスワイプして移動するときはオフにします。

10×10に収まらない画像は、プレビューや盤面の上に表示される「10×10に分けて遊ぶ」から分割できます。端の余りは空白で補い、完全に空白の区画は最初から完成済みです。区画ごとに「その他」から答えを見られます。

最大400区画に対応し、すべて完成すると枠のないドット絵をPNGで保存できます。小さな絵はドットをにじませずに拡大したPNGも選べます。途中の状態はページを開いている間だけ残ります。

プレイ時間は最初にマスを操作してからクリアまでを計測します。一時停止中は盤面が隠れ、時間は進みません。「答えを見る」を押すたびに1行につき1分が加算されます。分割の全体図では合計時間を表示し、「区画の時間を表示」で各区画の時間を確認できます。

## テスト
Node.jsがインストールされた環境で、次のコマンドを実行します。
追加のパッケージのインストールは不要です。

```sh
node --test tests/*.test.cjs
```

従来のPNG行データの幅と画素の値、白黒変換の明るさと透明度、縮小後のサイズを確認します。
パレット形式PNGの透明度と、フィルター方式0〜4で符号化された行も確認します。
