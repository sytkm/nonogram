# nonogram
PNG・JPEG・WebPからノノグラムを作成します。画像の変換はブラウザ内で行います。

従来のカラー問題に対応するPNGは、画像を選ぶとそのまま遊べます。完全に透明なマスは空白として扱います。盤面から同じ画像の白黒プレビューも開けます。JPEG・WebPではプレビューでカラーと白黒を切り替えられます。カラーでは近い色を最大7色にまとめ、透明な部分や白に近い部分を空白にします。

白黒の境目は画像内の明暗の分布をもとに自動で選びます。プレビューで境目とマス数を調整してから遊べます。最長辺が200ピクセルまでの画像は初期状態で元のマス数を使います。さらに大きい画像には最長辺40マスを提案し、縦横比を保ったまま200マスまで変更できます。

盤面の「なぞり塗り」をオンにすると、指やマウスで通ったマスをまとめて塗れます。盤面をスワイプして移動するときはオフにします。

10×10に収まらない画像は、プレビューや盤面の上に表示される「10×10に分けて遊ぶ」から分割できます。端の余りは空白で補い、完全に空白の区画は最初から完成済みです。区画ごとに「その他」から答えを見られます。

最大400区画に対応し、すべて完成すると枠のないドット絵をPNGで保存できます。小さな絵はドットをにじませずに拡大したPNGも選べます。区画をクリアするとその盤面で確認でき、「全体図に戻る」で一覧へ戻れます。途中の状態とクリア済み区画はブラウザに保存され、完成した区画はあとから見返せます。

プレイ時間は最初にマスを操作してからクリアまでを計測します。一時停止中は盤面が隠れ、時間は進みません。「答えを見る」を押すたびに1行につき1分が加算されます。分割の全体図では合計時間を表示し、「区画の時間を表示」で各区画の時間を確認できます。

「考え方ヒント」は、行・列の数字と現在の入力から、色や空白が確定する一マスとその根拠を示します。盤面の入力とプレイ時間は変わりません。「行・列ヒント」は、まだ完成していない横一行または縦一列をランダムに選び、色を塗って空白に斜線を付けます。プレイ時間には1分を加えます。どちらも通常の盤面と分割ノノグラムで使えます。

右上の歯車「設定」から、遊び方と共通設定を開けます。ヒント数字の固定、カラー問題の色記号、自動斜線などの設定は、同じブラウザで次に開く問題にも適用されます。

盤面上の「ヒント数字」で「チェック」「色を選ぶ」を切り替えられます。「チェック」では押した数字に印を付け、「色を選ぶ」では数字と同じ色をパレットで選びます。空白を示す「0」では色は変わりません。選んだ操作は、同じブラウザで次の問題にも引き継がれます。

「完成した行・列の空白に斜線」をオンにすると、塗りがヒント数字と一致した行・列の未入力マスに斜線が付きます。塗りと一緒に「元に戻す」で取り消せます。

画像の変換プレビューにある「答えが一つか調べる」で、ヒント数字に合う配置が一つか複数かを確認できます。大きな問題などでは制限内に判定できない場合があります。

新しく遊ぶ問題で答えが複数見つかった場合は、元画像の空白に青い斜線を加えて答えを一つに絞ります。青い斜線は問題の一部として固定されます。検査の上限内で一意性を確認できなかった場合は、行・列のヒント数字に合う配置でクリアになります。

## テスト
Node.jsがインストールされた環境で、次のコマンドを実行します。
追加のパッケージのインストールは不要です。

```sh
node --test tests/*.test.cjs
```

従来のPNG行データの幅と画素の値、白黒変換の明るさと透明度、縮小後のサイズを確認します。
パレット形式PNGの透明度と、フィルター方式0〜4で符号化された行も確認します。
