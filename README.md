# 画像でノノグラム

PNG・JPEG・WebPから、ブラウザで遊べるノノグラムを作るアプリです。画像の変換はブラウザ内で行います。

[公開サイトを開く](https://sytkm.github.io/nonogram/) · [サンプル問題で遊ぶ](https://sytkm.github.io/nonogram/?sample)

## 遊び始め方

1. 画像がなければ「サンプル問題で遊ぶ」を選びます。自分の画像で遊ぶには「自分の画像で作る」からファイルを選びます。
2. プレビューで画像を確認し、必要なら「色とマス数」で調整します。対応するパレット形式のPNGは、カラーのとき元の寸法と色を使います。確認や共有が必要なら該当する欄を使い、「遊び始める」の「この問題で遊ぶ」を押します。
3. 盤面の上と左の数字を手がかりに、下のパレットから色を選んでマスを塗ります。空白だと分かったマスには斜線を付けられます。隠れている色はパレットを左右にスクロールすると選べます。

進み具合は、同じブラウザに直近の1問が自動保存されます。ホームの「前回の続きから」で再開できます。詳しいルールとキーボード操作は、画面右上の「設定」から「遊び方」を開いて確認できます。

## 主な機能

- **画像の変換** — カラープレビューでは近い色を最大7色にまとめます。白黒プレビューでは明るさの境目を自動で選び、手動でも調整できます。プレビューで指定できる最長辺は200マスです。
- **分割ノノグラム** — 10×10に収まらない問題は、プレビューから「10×10に分けて遊ぶ」を選べます。最大400区画に対応し、すべての区画が完成すると1枚のPNGとして保存できます。
- **盤面の操作** — 拡大・縮小、「操作を取り消す」「取り消しを戻す」が使えます。「なぞり塗り」をオンにすると、指やマウスで通ったマスをまとめて塗れます。指で盤面をスクロールするときはオフにします。「ヒント数字」では、押した数字をチェックするか、その色を選ぶかを切り替えられます。
- **ヒントと確認** — 「ヒント・確認」から、考え方ヒント、行・列ヒント、矛盾チェック、答えの表示を使えます。行・列ヒントはプレイ時間に1分、答えの表示は1行につき1分を加えます。
- **答えの確認** — プレビューの「答えが一つか調べる」で、ヒント数字に合う配置を調べられます。遊び始めるときに複数の答えが見つかった場合は、元画像の空白に固定の青い斜線を加えて答えを一つに絞ります。制限内に一意性を確認できなかった場合は、ヒント数字に合う配置でクリアできます。

## 問題の共有

作成プレビューで、元の色を使う対応パレット形式PNGは「通常問題の共有リンクをコピー」または「Blueskyで共有」を選べます。通常問題のリンクには元のPNGが含まれます。

分割できる問題は、作成プレビューの「分割問題の共有リンクをコピー」で、同じ区画を最初から遊べるリンクを作れます。画像から変換した盤面の色と配置がリンクに含まれ、完成画像を復元できます。元の画像ファイルや、進み具合・プレイ時間・完成済み区画はリンクに含まれません。

分割問題の共有リンクの作成・読み込みには、ブラウザのgzip圧縮・展開機能が必要です。圧縮後のURLが8,000文字を超える問題は、リンクで共有できません。リンクが長い場合は、送信先のサービスで受け付けられる長さにも注意してください。

## ローカルで動かす

GitとPython 3が使える環境で、以下を実行します。

```sh
git clone https://github.com/sytkm/nonogram.git
cd nonogram
python3 -m http.server 8804 --bind 127.0.0.1
```

ブラウザで [http://127.0.0.1:8804/](http://127.0.0.1:8804/) を開きます。ビルドやパッケージのインストールは不要です。サーバーを終了するには、起動したターミナルで Ctrl+C を押します。

## テスト

Node.jsが使える環境で、リポジトリのルートから次のコマンドを実行します。追加のパッケージは不要です。

```sh
node --test tests/*.test.cjs
```

画像の読み込みと変換、盤面の操作や判定、ヒント、分割、進捗の保存などを確認します。開発時の確認手順は [AGENTS.md](AGENTS.md) を参照してください。
