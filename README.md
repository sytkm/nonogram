# 画像でノノグラム

PNG・JPEG・WebPから、ブラウザで遊べるノノグラムを作るアプリです。画像の変換はブラウザ内で行います。

[公開サイトを開く](https://sytkm.github.io/nonogram/) · [サンプル問題で遊ぶ](https://sytkm.github.io/nonogram/?sample)

## 遊び始め方

1. 画像がなければ「サンプル問題で遊ぶ」を選びます。自分の画像で遊ぶには「自分の画像で作る」からファイルを選びます。
2. プレビューで画像を確認し、必要なら「色とマス数」で調整します。対応するパレット形式のPNGは、カラーでは最初に元の寸法・色・空白を使います。色を保ったまま長い辺のマス数を減らしたり、「元のマス数に戻す」で元に戻したりできます。確認や共有には「問題を調べる」「共有」のタブを使えます。画面上部の「10×10に分けて遊ぶ」か「分けずに遊ぶ」を選びます。複数の区画に分けられる画像は分割を、10×10に収まる画像は通常プレイを先に表示します。
3. 盤面の上と左の数字を手がかりに、パレットから色を選んでマスを塗ります。「空白」で塗りを消し、「斜線」で空白の印を付けられます。スマホではパレットは画面下にあり、色が多いときは左右のボタンやスワイプで移動できます。広いPC画面では右側に色を並べます。

進み具合は、同じブラウザに直近の1問が自動保存されます。ホームの「前回の続きから」で再開できます。問題の種類・寸法・進み具合や、記録があれば最終保存日時も表示します。詳しいルールとキーボード操作は、遊んでいるときは、画面右上の「メニュー」から「遊び方」を開けます。

## 主な機能

- **日替わり問題** — 日本時間の午前0時に切り替わります。日付をもとに7×7の問題を生成し、行と列の推理で解ける配置を全員に同じように出題します。当日の進み具合は、画像やサンプルで遊んだ問題の保存とは別にこのブラウザに保存されます。
- **画像の変換** — 通常のカラーPNG（RGB・RGBA）・JPEG・WebPは、カラープレビューで近い色を最大7色にまとめます。白黒プレビューでは明るさの境目を自動で選び、手動でも調整できます。通常の画像変換で指定できる最長辺は200マスです。
- **分割ノノグラム** — プレビューから「10×10に分けて遊ぶ」を選べます。10×10に収まる問題は1区画になります。400区画を超える画像ではマス数を減らす方法を案内します。すべての区画が完成すると元の盤面の大きさでPNGを保存できます。
- **盤面の操作** — 盤面の近くに拡大・縮小・全体表示があり、「元に戻す」で直前の操作を取り消し、「やり直す」でその操作を再適用できます。「なぞり塗り」をオンにすると、指やマウスで通ったマスをまとめて塗れます。指で盤面をスクロールするときはオフにします。ヒントの数字は初期設定では押すとチェックでき、設定の「数字を押すと」で色を選ぶ操作に変更できます。スポイトでもヒントの数字から色を拾えます。
- **ヒントと確認** — 「ヒント・答え」から、考え方ヒント、行・列ヒント、矛盾チェック、答えの表示を使えます。行・列ヒントは選ばれた行・列の全マス数、答えの表示は盤面全体のマス数に、1マスあたり10秒を加えます。考え方ヒントはヒントが出たときに30秒、矛盾チェックは矛盾がなくても60秒です。同じ盤面で続けて同じ考え方ヒントやチェック結果を見るときは、追加では加算しません。
- **答えの確認** — プレビューの「答えが一つか調べる」で、ヒント数字に合う配置を調べられます。遊び始めるときに複数の答えが見つかった場合は、元画像の空白に固定の青い斜線を加えて答えを一つに絞ります。制限内に一意性を確認できなかった場合は、ヒント数字に合う配置でクリアできます。

## 問題の共有

共有リンクを初めて開くと、遊び方が表示されます。閉じると、受け取った通常問題や分割問題をそのまま遊べます。プレイメニューからホームに戻ると、編集前の共有問題も再開できるように保存します。別の問題が保存されている場合は、上書きする前に確認します。

作成プレビューの「共有」や、プレイ画面の「メニュー」内の「共有」から、通常問題のリンクをコピーしたり、Blueskyの投稿画面を開いたりできます。分割区画の「共有」では、元の全体図を共有します。リンクを開くと、プレビューした寸法・色・空白のまま、画像全体を1つの盤面で遊べます。対応するパレット形式PNGを元の色と寸法で使う場合、通常問題のリンクには元のPNGが含まれます。

分割できる問題は、分割問題のリンクもコピーまたはBlueskyで共有できます。分割リンクを開くと区画一覧から始まります。どちらのリンクにも、進み具合・プレイ時間・完成済み区画は含まれません。

変換した通常問題や分割問題の共有には、ブラウザのgzip圧縮・展開機能が必要です。圧縮後のURLが8,000文字を超えるとリンクを作れません。長いリンクを投稿できない場合は、リンクをコピーして別の方法で送るか、マス数を減らしてお試しください。

## ローカルで動かす

GitとPython 3が使える環境で、以下を実行します。

```sh
git clone https://github.com/sytkm/nonogram.git
cd nonogram
python3 -m http.server 8804 --bind 127.0.0.1
```

ブラウザで [http://127.0.0.1:8804/](http://127.0.0.1:8804/) を開きます。ビルドやパッケージのインストールは不要です。サーバーを終了するには、起動したターミナルで Ctrl+C を押します。

## テスト

Node.jsが使える環境で、リポジトリのルートから次のコマンドを実行します。追加のパッケージは不要です。

```sh
node --test tests/*.test.cjs
```

画像の読み込みと変換、盤面の操作や判定、ヒント、分割、進捗の保存などを確認します。開発時の確認手順は [AGENTS.md](AGENTS.md) を参照してください。
