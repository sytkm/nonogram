# 絵合わせパズルの個別仕様（たたき台）

[複数の遊び方の構想 #3](https://github.com/sytkm/nonogram/issues/3) にある「画像を分けたピースを並べて元の絵を作る」遊び方の案。**この文書は未確定で、実装開始や公開の承認を意味しない。** 共通の画面・互換性・品質の条件は [共通仕様](../puzzle-page-standards.md) に従う。塗り絵の実装・確認を先に進める。

## 目的と基本ルールの案

同じ画像変換プレビューから、ノノグラム・塗り絵に加えて「絵合わせ」を選ぶ。画像を長方形のピースに分け、2枚の位置を交換して元の絵に戻す。ピースは回転・反転しない。空きマスを作るスライドパズルにはせず、どの2枚も交換できるため、行き詰まりなく自分のペースで完成できる。

見た目が同じピース同士の交換は正解として扱う。元のピース番号との一致ではなく、完成した画素の並びが元画像と一致することをクリア条件にする。ランダムな配置は必ず未完成にし、少なくとも一組の違うピースがなければ開始せず、画像や分け方を選び直せるようにする。

## 入力・画面の案

- 1枚をタップ・クリックして選び、もう1枚を押すと交換する。同じピースをもう一度押すかEscで選択を解除する。選択枠とキーボードのフォーカス枠は別にする。
- キーボードはTabで盤面に入り、矢印で移動、SpaceまたはEnterで選択・交換する。初回は左上のピースにフォーカスを置く。位置と選択状態を読み上げられるようにする。
- ドラッグ操作は初回には含めない。交換の操作を誤って移動やスクロールとして扱わないようにする。
- 「見本を見る」で完成見本を表示する。表示中は入力と時間を止め、閉じると選択とフォーカスを戻す案。見本の時間加算はしない。
- 「元に戻す」「やり直す」は交換1回単位。「最初からやり直す」は進行と時間をリセットし、同じ開始配置に戻す案。破棄前に確認する。
- 完成時は完成画像と時間を表示する。結果を閉じて絵を見たり、結果を再表示したりできる。

## 画像取り込み・分け方の案

既存の変換結果（画素配列・RGBパレット・空白）を使い、元画像の切り抜き・減色・マス数調整を共用する。空白は絵の一部としてピースに含め、空白のみのピースも交換できる。自作の最小例題からも開始できる。

初回の分け方は3×3、4×4、5×5の候補とし、既定は3×3案。分ける行数・列数より元画像が小さい場合はその分け方を選べない。端に余りがある場合も元の寸法を保ち、余白を追加しない。境界は `floor(位置 × 元寸法 / 分割数)` で決める。

端の余りがある画像ではピースの画素寸法が異なる。盤面の表示枠は同じ大きさにし、交換中のピースは枠に合わせて表示する。クリア判定では画像を拡縮せず、それぞれの元の画素と寸法を比較する。正解時に元画像を正しい縦横比で表示する。表示の歪みが気になる場合は、開始前に割り切れる寸法へ調整する別案と比較して決める。

初回上限は最長辺200マス・背景込み16色案。パレットPNGが上限を超える場合は、開始前に「色とマス数」で調整してもらう。既存のノノグラムで使用できる画像を、このモードの上限によって制限しない。

## 最小の例題と正解

実装確認に使う自作の2×2例題。各ピースは1画素で、4色はすべて異なる。公開サンプルは別途、絵として楽しめる3×3の自作画像を用意する。

| 記号 | 色 |
| --- | --- |
| A | 赤 `#D64545` |
| B | 青 `#4D8FE8` |
| C | 緑 `#52A66B` |
| D | 黄 `#F5D34D` |

開始配置：

```text
B A
D C
```

正解：

```text
A B
C D
```

左上と右上を交換し、次に左下と右下を交換すると2手で完成する。同一色のピースが複数ある別例で、ピースの識別番号が異なっても見た目が同じなら正解になることも確認する。

## 保存・共有・時間の案

- 途中保存と再開を入れる。キーは `nonogram:picture-pieces:progress:v1` 案。形式名・バージョン・元の問題・開始配置・現在配置・履歴・経過時間を保存し、ノノグラムと塗り絵を上書きしない。別の絵合わせ問題を始める前には既存保存の概要と入れ替え確認を出す。
- 問題共有は元画像と分け方と開始配置を含め、同じ問題から始められるようにする。途中状態と時間は含めない。共有形式は専用識別子とバージョンを持ち、旧ノノグラム・塗り絵のリンクを保つ。初期配置は全ピースが一度ずつ現れる順列として検証する。
- 時間は最初の交換から計り、プレイ中と結果に表示する。選択のみ・同じピースの選択解除では開始しない。別タブ・ページを閉じている間・見本表示中は停止し、再開時に引き継ぎ、クリア時に止める。
- 完成画像のPNG保存と問題共有をクリア結果から使えるようにする。途中状態の画像保存は含めない。

## 初回に含めないものの案

ピースの回転・反転、ドラッグ、制限時間、順位・最短手数の競争、日替わり、ヒントの時間加算、自由な分割数指定、スライド式操作。

## 利用者と決めること

1. **名前と交換ルール。** 表示名「絵合わせ」で、2枚を選んで交換する方式でよいか。
2. **分け方と端の扱い。** 3×3を既定にして4×4・5×5も選べるか。端が割り切れない場合の一時的な拡縮表示を許すか、事前調整するか。
3. **見本・履歴・時間。** 見本をいつでも無加算で見られるか。元に戻す・やり直す・最初からやり直すを初回から含めるか。時計の表示・停止条件は上記でよいか。
4. **初回の範囲。** 画像上限・保存・共有・完成PNG保存を上記の案で含めるか。

## 受け入れ条件の案

- 例題をマウス・タップ・キーボードで2手で完成できる。同じピースの再選択とEscは交換に数えず、時間も開始しない。
- 同じ見た目のピース、空白のみのピース、端の寸法が異なるピースでも、表示とクリア判定が一致する。開始配置は解ける未完成の状態で、出題できない単色画像には理由を示す。
- 選択と交換、元に戻す・やり直す、見本、途中保存・再開、完成結果・PNG保存・共有を、確定した範囲で一通り試す。
- 320px・一般的なスマホ縦・スマホ横・PCで、選択枠とフォーカス、表示の縦横比、モーダルの開閉とフォーカス復帰を確認する。スマホ実機と幅シミュレーションは区別する。
- 保存拒否・容量不足・破損データ・重複や欠落を含む配置・不正共有URLで復帰手段を示す。ノノグラムと塗り絵の旧URL・共有・途中保存を維持する。
- 共通仕様の品質5項目をPRに記録し、自動テストと差分チェックを実行する。
