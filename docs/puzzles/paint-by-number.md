# 塗り絵の個別仕様

[複数の遊び方の構想 #3](https://github.com/sytkm/nonogram/issues/3) の最初の追加候補。同じ画像からノノグラムと塗り絵を選んで遊べるようにする。画面・互換性・品質の確認には [パズル画面の追加・移行の共通仕様](../puzzle-page-standards.md) を使う。

## 基本方針とルール

- 自分のペースで気軽に塗れる遊びにする。画像の変換プレビューと小さなサンプルから「塗り絵」を始められる。
- 塗るマスに色番号を出し、パレットには番号と色を併記する。問題ごとにパレットの塗り色を同じ順序で 1 から採番する。空白に番号は出さず、入力対象にも含めない。
- 選んだ色が合っていればマスを塗り、番号を隠す。色が違うマスや塗り済みのマスへの入力は無視する。警告、効果音、時間加算は行わない。
- すべての対象マスを塗ると自動でクリアする。完成画像を表示する。

## 操作と盤面

- タップ、クリック、キーボードで塗れる。開始時は1色目を選択し、そのパレットボタンにフォーカスを置く。キーボードで盤面に移動して塗れ、選択色とフォーカス位置を見分けられる。
- なぞり塗りは初期状態でオン。通過したマスのうち選択色と合う未着色のマスだけを塗る。タッチではタップの判定に余裕を持たせる。マスを直接押したときはそのマスを優先し、境界付近で候補を一つに絞れる場合にだけ近くの対象マスを補う。判定の具体的な幅は実機で調整する。
- 拡大・縮小と移動はノノグラムと同じ使い方にする。「－」「＋」「全体」「標準」とミニマップを備え、ピンチと2本指の移動を使える。指の本数の切り替えや倍率変更で盤面に意図しない入力が入らないようにする。

## 画像取り込み

- ノノグラムと同じ画像取り込みと変換結果を使う。変換を伴う通常画像は、元画像または切り抜きの最長辺を超えず、最長200マスまで。減色の上限は背景込み16色（塗り色は最大15色）とし、マス数や色の結果は開始前のプレビューで確認できる。
- 通常のPNG・JPEG・WebPでは切り抜きと解除を使える。パレットPNGは切り抜きの対象外とし、減色しても空白の位置を保つ。現行ノノグラムでパレットPNGの「元の配色」「元のマス数」を使うと変換時の上限を超える場合がある。塗り絵では元の配色・寸法にも最長辺200マス・背景込み16色（塗り色は最大15色）の上限を適用する。上限を超える場合は開始できない理由を示し、開始前に「色とマス数」で調整できるようにする。
- ノノグラムのヒント生成・正解判定と塗り絵のルールは分ける。塗るマスがゼロの場合は、塗り絵を始められないことと、画像や変換条件を選び直せることを案内する。

## 初回に含める機能

- 途中保存と再開、完成画像の保存、問題の共有、時間計測を入れる。表示上の問題形式名は「塗り絵」とする。保存と共有には形式の識別子とバージョンを持たせる。塗り絵の途中保存キーは `nonogram:paint-by-number:progress:v1` とし、既存のノノグラムの保存キーとは分ける。既存の共有リンクは従来どおり開けるようにする。
- 元に戻す・やり直す、最初からやり直す、分割、ヒントは初回の範囲外とする。

## クリア後・時間・色選択の確定仕様

- **クリア後と記録の扱い。** 完成画像をPNGで保存し、問題の共有リンクをコピーできる。結果を閉じて完成盤面を見たり、結果を再表示したりできる。共有するのは問題だけで、塗った状態と時間は含めない。時間は最初に正しく塗ったマスから計り、ページを閉じている間や別タブを表示している間は計測せず、再開時に引き継ぎ、クリア時に止める。時間はノノグラムと同じ表示方法でプレイ中にも表示し、クリア結果でも確認できるようにする。
- **背景とパレットPNGの上限。** 通常カラー変換では、白に近い部分が空白になる現行の扱いを使う。パレットPNGでは確定済みの空白をそのまま保つ。元の配色・寸法が塗り絵の対応上限を超える場合は、開始前に「色とマス数」で調整してもらう。
- **色の自動切り替え。** 選択中の色の対象マスをすべて塗ると、入力操作が終わって指やマウスを離した時点（キーボードは1マスの入力時点）で、番号順で次の未完了色へ自動で切り替える。後ろに未完了色がなければ先頭に戻って探す。塗り終えた色は完了とわかる表示にし、クリック・タップ・キーボードのいずれでも選択できなくする。未完了色は利用者が選び直せる。すべての色を塗り終えたら、次の色へ切り替えずにクリアする。

## 受け入れ条件

- 例題で1色目が選択され、フォーカスが見える。合う色で塗ると番号が消え、違う色・空白・塗り済みのマスは変わらない。5色の対象マスをすべて塗ると、その時点でクリアする。
- PCとスマホ縦・横で、タップ・クリック・キーボード、なぞり塗り、タップ判定の余裕、拡大・縮小・移動・ミニマップを確認する。狭い幅や縮小時に境界付近をタップし、意図しないマスが塗られないかを実機で確認する。
- 1色を塗り終えると次の未完了色へ自動で切り替わり、塗り終えた色はポインターとキーボードで選べない。最後の色ではクリアし、途中再開でも完了色を選択しない。
- 同じ画像から両方の遊び方に進める。通常画像の切り抜き・解除と、パレットPNGの減色・空白・元の配色と寸法の扱いを確認する。画像の上限超過や塗るマスがゼロの場合も試す。
- 途中まで塗って再開し、塗ったマスと経過時間を復元できる。プレイ中の時間表示、最初の正しい入力での計測開始、別タブ・ページを閉じている間の停止、クリア時の停止を確認する。共有URLから塗り絵が開き、完成画像を保存できる。既存のノノグラムの公開URL・共有リンク・途中保存も確認する。
