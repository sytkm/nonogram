# 新規パズルの着手前に行った品質点検

対象は公開ブランチの `e08c909` と、今回の品質修正の確認版。評価は、参照できた元のChatGPT相談と8つのNonogram開発チャット、関連Issue・コード・既存テストに基づく。品質の項目と今後の確認方法は [パズル画面の追加・移行の共通仕様](puzzle-page-standards.md) に記載した。

| 観点 | 確認したこと | 判断と対応 |
| --- | --- | --- |
| 有効性 | 行・列のヒントとクリア判定、固定斜線、色と透過の画像処理、通常・分割の共有、日替わりの再現性を自動テストで確認。Chromeで日替わりと通常・分割の保存を開き、サンプルをキー操作でクリアし、結果を閉じて再表示した。通常の共有と無効な共有も確認した。 | 確認した経路では動作した。パズルを追加するたびに、そのルールに沿った最小の正解・不正解・完了を確かめる。 |
| 効率性 | ホームから日替わりを1操作で開始できた。Chromeでクリックから盤面表示を検知するまで、今回の短い計測は約4〜13ms。検査のWorkerは3秒の待ち上限を設け、日替わり生成の試行回数にも上限がある。 | 同じMacのChromeで合成した200×200盤面は準備を含め約120ms、キー入力から次の描画まで約10ms。いずれも単発の参考値。低速端末の操作感や、盤面・色数による最悪時の所要時間は未評価。 |
| 満足性 | 操作名を過去の決定と照合。設定、遊び方、作成時の案内、検査と矛盾チェックに「ヒント数字」が残っていた。 | 今回の修正で「ヒントの数字」に統一。利用者本人の使い心地は別途確認する。[PR #205](https://github.com/sytkm/nonogram/pull/205) |
| リスク回避性 | 保存の上書き確認と容量不足時の動作を自動テストで確認。問題データが欠けた保存でも、修正前は「前回の続きから」が表示されることを再現。 | 再開に必要な項目を読み出し時に確認。再開を案内できない記録はホームで表示せず、保存データは保持する。旧形式の有効な通常・分割保存は再開できた。[PR #204](https://github.com/sytkm/nonogram/pull/204) |
| 利用状況網羅性 | GitHub Pagesと同じ `/nonogram/` のパスで、ChromeのPC（1280×900）、スマホ縦（320×700）、スマホ横（844×390）を確認。タッチ操作・ピンチ・一時停止・ダイアログなどに関する既存テストも実行した。 | Safari・iPhone実機や読み上げの利用感は未評価。スマホ幅の確認と実機の確認は分けて報告する。 |

製品側は、公開ブランチの自動テスト143件と、保存の回帰テストを追加した確認版の144件が成功。画像、ルール、描画・入力、プレイと保存、共通UIの責務を [コードの構成](code-organization.md) と照合した。次の画面では、画像入力とルールの境界から進め、旧リンクと保存を確かめながら、動作変更とファイル整理を個別に検証する。

## 過去の確認で繰り返し修正した箇所

- 画像と互換性では、透過PNGの空白、パレット画像の大きさと色、RGB写真のカラー、通常・分割の共有と再開を確認した。[パレットPNGのプレビュー #84](https://github.com/sytkm/nonogram/issues/84) · [作成・プレイの整理 #107](https://github.com/sytkm/nonogram/issues/107)
- 画面では、全ページとダイアログで共通デザインを揃え、操作の意味、タブと設定の区別、初回案内からの復帰を揃えた。[初回共有の案内 #83](https://github.com/sytkm/nonogram/issues/83) · [遊び方 #182](https://github.com/sytkm/nonogram/issues/182)
- 入力では、スマホのパレットの見切れ、なぞり塗りとスクロール、ピンチ、スポイトで拾える対象を確認した。[スマホのボタンとパレット #62](https://github.com/sytkm/nonogram/issues/62) · [ピンチ #177](https://github.com/sytkm/nonogram/issues/177) · [スポイト #183](https://github.com/sytkm/nonogram/issues/183)
- 開発では、コード整理の責務・JSDoc、旧動作の確認、PRの分割、誰でも辿れる試し方、公開後の配信確認を定着させた。[リファクタリング #47](https://github.com/sytkm/nonogram/issues/47)
